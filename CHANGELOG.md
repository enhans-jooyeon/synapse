# Synapse changelog

Versioning is **release-based** (design.md §6): ongoing work lands under **Unreleased**; the version bumps only when a release is cut for the team.

## Unreleased

- **`preview.html` — interactive dropdowns + unified multi-section example layout (preview-only).** Select, Combobox, and DatePicker (range + datetime) triggers now open their listbox/menu/calendar as an anchored popover on click (Escape / outside-click close; single-select updates the value; combobox multi-select stays open; calendar day/preset closes). Multi-section stories now render as **one `.example` wrap with a full-bleed `.ex-div` rule between sections** (headings inline) instead of several separate boxes, and the redundant "On this page" heading list was removed. Example cells are pre-sized once on load to the fully-expanded dropdown height so opening causes no layout shift or spill past the frame. Fixed along the way: focus outline now appears on click regardless of pointer position (hover no longer outranks focus); Combobox menu checkboxes no longer inherit the text-field box styling. No spec/token/manifest change; gate green.

- **InputGroup add-on segments align to the input body's side padding (spec).** Codified that every fused add-on segment (text prefix/suffix, dropdown, button, ⌘K hint) takes the **same horizontal side padding as the input body it is attached to** (`control-padding-x`; a dropdown's chevron uses that value as its right inset), so the group aligns on a single inset instead of reading tighter than a plain field. Written into `components.md` (Input · Add-ons subsection) and the manifest `Input (text)` key_rules (rebuilt); `preview.html` already implemented it (in-group input, `segTxt`, `.pg-sel`, kbd span moved from `space-2`/8px to `control-padding-x`/12px, chevron right inset to 12px with 32px text clearance). Gate green.

- **Text fields reverted from borderless-filled to outlined-white (governance; fixes "inputs look disabled").** The filled field anatomy used a `bg.sunken` fill that is tonally identical to the `bg.disabled` fill (`#F4F4F6` in light mode), so at-rest inputs were indistinguishable from disabled ones. Text fields are now **white `bg.page` + a 1px `border.default` perimeter**; hover steps the border to `border.strong`; focus swaps the border to the neutral `border.focus-input` (1px, no offset ring — entry controls keep the border-only indicator, non-entry controls keep the blue flush ring); **disabled keeps the grey `bg.disabled` fill as the single unambiguous filled state**; read-only keeps the faint `bg.surface` fill; error keeps `border.error`. No new tokens; scope limited to editable fields (recessed non-field `bg.sunken` surfaces — skeletons, code blocks, trays, tracks, in-menu search rows — unchanged). Gate green (ui + tokens 0/0).

- **Spacing tokens renamed to the Tailwind 4px-multiplier index (breaking, names only).** The `--sy-space-*` scale moved from literal-px names (`space-16` = 16px) to **Tailwind-style index** names (`space-4` = 16px; name × 4px = value). Rationale: px-literal names collide with an LLM's Tailwind priors — the model reads `4` as 16px — and silently emit wrong sizes the gate can't catch (a valid-but-wrong token). **Pixel values are unchanged; this is purely a naming change.** Map: 2→`0_5` · 4→`1` · 6→`1_5` · 8→`2` · 10→`2_5` · 12→`3` · 16→`4` · 20→`5` · 24→`6` · 28→`7` · 32→`8` · 40→`10` · 48→`12` · 64→`16` · 80→`20` · 96→`24` · 128→`32` · 160→`40` · 192→`48` · 224→`56` · 256→`64` · 320→`80` · 384→`96`. The three sub-grid fine steps use an underscore (`space-0_5` = 2px, `space-1_5` = 6px, `space-2_5` = 10px) because a dot is invalid in a CSS custom-property name. Executed as one **atomic single-pass rename** (1104 refs across `tokens/synapse.css` + `.tokens.json`, `preview.html`, the specs, and storybook), which sidesteps the crossover collision (old `space-16`→`space-4` while old `space-64`→`space-16`); every used token verified defined, gate green. `foundations.md` §3 documents the convention. Stack is CSS-variable-based (not Tailwind), so this is a var rename, not a Tailwind-config change. Supersedes + archives `proposals/2026-07-28-spacing-multiplier-rename.md`. **Breaking for any consumer referencing `--sy-space-*` by name.**
